# Ktor Task Server

Проект на Kotlin и Ktor.

В проекте есть работа с задачами, пользователями, JWT, ролями, базой данных, Swagger и WebSocket.

## Что есть

- CRUD для задач
- регистрация и вход
- JWT
- роли USER и ADMIN
- PostgreSQL
- WebSocket
- Swagger
- обработка ошибок
- логирование
- Docker

## Запуск

Через IntelliJ IDEA из `Application.kt`.

./gradlew run
